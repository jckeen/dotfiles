## 2026-11-02 — feat(antigravity): private permission overlays, unask promotions, and `--mode auto` launcher default

- **`claude/scripts/agy-apply-permissions.py`**: accepts repeatable `--overlay <path>` JSON files and an optional top-level `"unask"` list in both the baseline and overlays. Overlays can append `allow` rules and promote baseline `ask` rules out of `permissions.ask` (stripping them from both the baseline and live `settings.json` `ask` lists) without editing the tracked baseline. `deny` rules in overlays are rejected (`deny` remains single-source in `antigravity/permissions.json`), symlinked `--settings` files are refused, and `0600` permissions are enforced on existing `settings.json` files even when content is unchanged.
- **`antigravity/permissions.json`**: retires `read_file(~/dev/)` so Antigravity's `bwrap` sandbox mount map does not overwrite `write_file(~/dev/)` and the `~/dev` workspace mount from read-write to read-only. Promotes `command(bunx)` and `command(npx)` from `permissions.ask` to `unask` so prefix matching no longer shadows `command(bunx tsc)` or prompts on every JS/TS test/lint invocation. Adds `mcp(playwright/*)` and `mcp(github/*)`, localhost and GitHub `read_url` grants, common dev/test/git/shell rules (`pytest`, `uv run`, `npm test`, `npm run`, `pnpm`, `cargo`, `go`, `git checkout`, `git restore`, `git branch -d`, `git worktree prune`, `rm -f`, `sed`, `cd`), and `~/dev/dotfiles/...` check script prefixes.
- **`setup.sh`, `check-antigravity.sh`, and `.bash_aliases`**: pass `--overlay "$AGY_MEMORY_REPO/permissions.local.json"` to `agy-apply-permissions.py` when present, invoke `$AGY_MEMORY_REPO/bootstrap.sh` from `setup.sh` and the `agy` shell wrapper, default interactive `agy` launches to `--mode auto` unless `--mode` is already supplied, rewrite `agy -c <id>` / `agy --continue <id>` (and `=<id>` forms) to `--conversation <id>` while keeping bare `-c` / `--continue` intact, and allow `~/.gemini/config/GEMINI.md` to be materialized as a regular file so Antigravity's `trustedCLIGatedPaths` symlink resolution does not mount `~/dev` read-only inside the terminal sandbox.
